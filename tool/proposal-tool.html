Cloud Architecture & Disaster Recovery

PeopleHub is deployed on Microsoft Azure using a resilient, high-availability architecture designed for enterprise workloads. The proposed environment includes:

Reference architecture
1CloudflareEdge layer — DNS, TLS termination, DDoS protection, WAF and CDN caching.
2FirewallPerimeter filtering and intrusion prevention; only required ports are exposed.
3Load balancersDistribute traffic across redundant nodes with health checks and failover.
4Front-end serversWeb and mobile application tier serving the user interface.
5Back-end serversApplication and API tier handling business logic, payroll and attendance processing.
6Database serversPrimary database with high-availability replica; encrypted at rest.
WDMS server
Separate device-management server syncing biometric terminals to the back-end over a dedicated secured channel.
On-site backup
Local backup servers holding scheduled snapshots at the client site.
Geo-redundant backup
Off-region backup servers protecting against site-wide or regional loss.

Traffic enters through Cloudflare and passes the firewall and load balancers before reaching the application tiers; only the back-end tier can reach the database. The WDMS server and both backup layers sit outside the public path.

Security Practices & Policies

Network & perimeter
All inbound traffic passes Cloudflare WAF and DDoS protection, then a managed firewall. Administrative access is restricted to allow-listed addresses over VPN.
Encryption
TLS 1.2+ in transit and AES-256 encryption at rest, including database volumes and backup media.
Access control
Role-based access with least-privilege defaults, enforced password policy, multi-factor authentication for administrators, and full audit logging of privileged actions.
Patching & hardening
Operating systems and platform components patched on a defined cycle; servers built from hardened baseline images with unused services disabled.
Monitoring
Continuous availability and performance monitoring with alerting; security events logged centrally and retained for review.
Backup integrity
Backups are encrypted, access-controlled, and restore-tested periodically to confirm recoverability against agreed RPO and RTO targets.

Backup & Disaster Recovery

A structured backup and disaster recovery topology protects your organization's workforce data:

Automated daily database backups, retained for a minimum of one month.
Weekly backups retained for one to three months.
